## CNN-17 이후 실험 방식 변경
지금까진 기본적인 튜닝만 진행. 막히지는 않고 아직 뭔가 해볼 수 있는 기본 튜닝 또는 추가 기법이 있긴한데
그 전에 해보고 싶은 것을이 있다.

- 그리드 탐색 횟수 계산 -> 후보값 개수가 정해져야 실제 횟수 계산 가능
- 랜덤 서치 -> 탐색 범위가 먼저 필요
- K-Fold 교차검증 -> 이것도 할려고 헀는데, 찾아보니 CNN은 학습 비용이 너무 커서 범위가 없으면 오래 걸린다 (그냥 돌릴까 하는데 그건 좀)

### 그럼 17 이후에는 무엇을?
= 먼저 탐색 범위를 설정하자. 

1. 탐색할 하이퍼파라미터 선정
2. 각 파라미터의 탐색 범위 설정
3. Grid Search 총 실험 횟수 계산
4. 너무 많으면 Random Search로 축소
5. 좋은 후보 1~3개만 K-Fold로 재검증
6. 마지막에 Test Set 평가

그럼 줄바꿈 줄이고 **한 줄에 여러 정보를 붙이는 식**으로 가면 돼.

## CNN-18 (탐색 범위 설정)

CNN-17 이후 바로 성능만 올리기보다, 다음 Grid Search / Random Search에 쓸 탐색 범위부터 잡기

탐색 범위: Learning Rate 0.0003 / 0.0005 / 0.001 / 0.002, Dense 64 / 128 / 256, L2 0 / 0.00001 / 0.0001 / 0.0005

공통 설정: Filter 32 → 128 → 128, Epoch 10, Batch Size 128, Adam, Dropout 0.3, Seed 42, Input 0~1 정규화


### 최고 결과

대충 보면 Learning Rate는 0.001 근처, Dense는 128~256, L2는 없음~아주 약하게 넣는 쪽이 괜찮아 보임

다음 탐색 범위는 Learning Rate 0.0008~0.0015, Dense 128~256, L2 0~0.00002 정도로 좁히기
